# 🛍️ Retail Sales Analysis

## 📊 Project Overview

This project analyzes retail sales data using interactive visualizations to identify sales trends, product performance, and other business patterns.

## 🛠️ Tools Used

- Flourish
- Data Visualization
- Exploratory Data Analysis
- Business Analytics

## 🎯 Project Objective

The objective of this project is to transform retail sales data into clear and interactive visualizations that can help businesses understand sales performance and identify important trends.

## 💡 Business Value

The analysis demonstrates how sales data can be transformed into visual insights that support data-driven business decisions.
